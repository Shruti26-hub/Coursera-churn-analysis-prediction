# 📊 Coursera-Style Churn Analysis & Prediction using Machine Learning

> **An end-to-end Data Analytics and Machine Learning case study designed to identify churn patterns, predict at-risk users, and generate actionable business insights for a Coursera-style EdTech platform.**
>
> ## ⭐ Project Highlights

- Built an end-to-end churn prediction pipeline using Python and Scikit-learn.
- Performed exploratory data analysis and feature engineering.
- Developed historical and predictive Power BI dashboards.
- Generated actionable business recommendations for user retention.
- Implemented risk segmentation and revenue-at-risk analysis using synthetic data.

---

# 🚀 Project Overview

Customer retention is one of the biggest challenges for online learning platforms. This project explores the factors influencing user churn and leverages Machine Learning to proactively identify users who are likely to discontinue their learning journey.

Using a **synthetic dataset modeled on a Coursera-style platform**, this project combines:

✅ Data Cleaning & Preprocessing

✅ Exploratory Data Analysis (EDA)

✅ Feature Engineering

✅ Machine Learning (Logistic Regression & Random Forest)

✅ Power BI Dashboarding

✅ Business Impact Analysis

The objective is not only to predict churn but also to provide practical, data-driven retention strategies.

# 🎯 Business Problem

Online learning platforms often lose users before course completion due to declining engagement and inactivity.

### Key Questions Answered:

- Which users are most likely to churn?
- What factors contribute to churn?
- Which regions contribute the highest revenue risk?
- How can retention strategies be improved?

# 📈 Historical Analysis Dashboard

The Historical Dashboard focuses on understanding past user behavior.

### KPIs

- Churn Rate
- Average Engagement
- Average Completion Ratio

### Insights

- Users inactive for longer periods are more likely to churn.
- Engagement and completion rates strongly influence retention.
- Certain countries contribute disproportionately to churn volume.
- Subscription plans exhibit different churn behaviors.

# 💡 Business Recommendations

Based on the analysis, the following strategies are recommended:

### 🔔 Smart Progress Notifications

Send personalized reminders when learners:
- Reach 50% course completion
- Become inactive
- Miss learning streaks

---

### 🎮 Gamified Learning Experience

Introduce:
- Achievement badges
- Learning streaks
- Progress milestones
- Interactive challenges

to improve long-term engagement.

---

### 🌍 Region-Specific Retention Campaigns

Prioritize countries contributing the highest revenue risk.

---

### 🎯 Personalized Interventions

Instead of blanket discounts, focus on:
- Mentor support
- Learning recommendations
- Progress summaries
- Re-engagement campaigns
